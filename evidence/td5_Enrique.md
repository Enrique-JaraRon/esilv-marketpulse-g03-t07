# TD5 — Branche distante et Pull Request

## Mon travail

Pour ce TD, j'ai travaillé sur la documentation du projet MarketPulse. J'ai créé une branche appelée `feature/document-marketpulse-execution` pour ne pas modifier directement `main`.

Dans le fichier `docs/RUN_MARKETPULSE.md`, j'ai expliqué simplement comment lancer le programme avec `python src/main.py`, quels fichiers de données sont utilisés et ce qu'on doit voir dans le terminal.

## Utilisation de Git et GitHub

J'ai enregistré mon travail avec un commit, puis envoyé ma branche sur le GitHub de notre équipe.

Ensuite, j'ai créé la Pull Request n°1 vers `main`. J'ai vérifié dans **Files changed** que seul mon fichier de documentation avait été ajouté.
